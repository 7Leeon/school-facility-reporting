# Branding assets

Drop your own files here (same names) to replace the defaults:

- `nvc-logo.png` - NVC logo. If missing, the app loads the logo from the official site (https://nvc.edu.ph/wp-content/uploads/2024/12/logo.png), and if that fails shows a letter badge.
- `campus-banner.jpg` - wide campus photo (about 1600x400, under 300 KB) shown at the top of every dashboard after login. If missing, a burgundy gradient is shown.

Only use photos you have permission to use (for example, ask the NVC administration or take your own). Do not use unofficial images as if they were official NVC assets.
